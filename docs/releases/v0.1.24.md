## Security

gitdr is now built with Go 1.26.10, which fixes GO-2026-6809 in `crypto/x509`. Certificate verification now distrusts intermediate certificates that are known to be compromised. Every HTTPS connection gitdr opens, to a source or to a destination, goes through this check, so the fix applies to every run. v0.1.23 and earlier were built with Go 1.26.9.

Nothing else changes in how gitdr runs. The manifest stays `gitdr.manifest/v5`, and `--output json` is unchanged.

## Dependencies

The AWS, Google Cloud and Azure SDKs, `golang.org/x/crypto`, `x/net` and `x/text` move to their latest minor and patch releases.

The release workflow's actions move to their latest minor and patch releases. The release is still signed with cosign 2.6.5, with the same signature files, so the verify commands in the README still apply.
